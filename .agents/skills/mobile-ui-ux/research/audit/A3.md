## CONTRADICTIONS

2. Pressed feedback: design-tokens §7 "one frame" vs SKILL/principles/checklists "≤ ~100 ms" vs motion `feedback.latency` ≤ 100 ms.
3. Motion ceiling wording: principles #10 and SKILL §3 say "100-300 ms"; motion/decision-rules 71/checklists allow 300-400 full-screen (500 ceiling). Reconcile as "100-300 for surfaces".
4. Undo/snackbar time: principles #5, states-feedback and components say ≥ 10 s (`[H]`); motion §6 says "long enough to read"; motion Copy confirmation 1.5-2 s; note 03 cites MDC defaults 1.5/2.75 s. Different intents, but nothing states that the 10 s rule overrides library defaults.

6. Touch size on web: SKILL says 44 CSS px, design-tokens `size.touch.min = 48`, principles #8 "≥ 48", data-dense rows "44pt/48dp". Not wrong, but a web agent gets two numbers.
